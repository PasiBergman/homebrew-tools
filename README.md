# Homebrew tap for PasiBergman's own formulaes and casks

## How do I install these formulae?

`brew install pasibergman/tools/<formula>`

Or `brew tap pasibergman/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pasibergman/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
